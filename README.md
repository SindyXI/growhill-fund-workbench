# Growhill fund research workbench

This repository hosts the encrypted static files for the external review version of the fund research workbench. The published files contain ciphertext only. The access code is shared separately with authorized viewers.

The content is intended only for approved Hong Kong professional investors. Access to the files is controlled by a shared code; distributing the code remains a separate decision.

The site is built from the maintained workbench source. Rebuilds use fresh random encryption salts and nonces. GitHub Pages serves the encrypted files; decryption happens in the browser.
